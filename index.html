Carregue a base para começar

O painel lê os arquivos .xlsx direto do seu computador. Nada é enviado para a internet: os dados ficam guardados só neste navegador até você carregar uma base nova.

  1. Use um arquivo com todas as abas ou uma pasta com vários arquivos.
  2. Cada aba precisa ter as colunas NUM_LIGACAO, Referência, ULTIMO_CONTRATO e as colunas de faturamento e economias.
  3. Só as linhas com ULTIMO_CONTRATO = SIM entram na análise.
